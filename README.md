# Online Classes & Assessments — Phase 1

Phase 1 includes online class scheduling and live classrooms, online class assessments, and assessment creation. Teachers manage classes and assessments; students join classes and participate in assessments.

The app opens on Online Classes. Standalone exams, proctoring, evaluation dashboards, report cards, results publishing, and administration screens are excluded from this phase.

This is a React/TypeScript frontend demo using mock data and in-memory state. Shared legacy types and context data remain for compatibility; removed feature screens and navigation are no longer included in the app.

## Development

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run lint`
